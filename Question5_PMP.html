PMP Exam Question 5

A project manager is leading a software development project using an agile methodology. Halfway through the project, a key stakeholder requests a significant change that would alter the project's core functionality. The project manager needs to evaluate this change request.

What should the project manager do FIRST?

A
Immediately implement the change to satisfy the stakeholder.
✓
B
Reject the change request to maintain the project scope.
✓
C
Assess the impact of the change on the project's scope, schedule, and cost.
✓
D
Escalate the issue to senior management for a decision.
✓
Explanation

In agile project management, while changes are welcomed, they must still be properly evaluated for their impact on the project. The project manager should first assess how the proposed change will affect scope, schedule, and cost before making any decisions. This evaluation is essential for informed decision-making and maintaining project control. It allows the project manager to present the stakeholder with a clear picture of the implications, facilitating a more collaborative and evidence-based decision-making process.

📋 Change Management 🔄 Agile
⭐ Correct: C
